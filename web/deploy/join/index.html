Play on PSNode

One-time setup for Windows. Takes about a minute.

  1. Download PSNode setup
  2. Double-click PSNode-Setup.cmd. If Windows says it protected your PC, click More info and then Run anyway. Click Yes when it asks for administrator rights.
  3. Type 1 and press Enter.
  4. Close Growtopia completely and open it again.
  5. On the login page, type the server name your friend gave you, then log in or create an account.
Going back to the official game

Run the same file again and type 2. It removes everything it added.

What the setup changes

It adds 4 lines to your hosts file so Growtopia asks PSNode which server to join, and it trusts the "PSNode Game CA" certificate. That certificate only works for growtopia1.com and growtopia2.com, so it can't be used for any other website. You can open the file in Notepad to read it before running it.
