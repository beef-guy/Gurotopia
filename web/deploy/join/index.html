Play on PSNode

One-time setup for Windows. Takes about a minute.

ATTENTION: read this before you play

To play on PSNode you have to run a setup file on your PC, once. Growtopia only logs in to servers your PC trusts, so without this you can't connect. Almost every private Growtopia server works this way, usually without telling you. We'd rather tell you.

The setup makes exactly 2 changes:

  • It adds 4 lines to your Windows hosts file, so Growtopia connects to PSNode instead of the official servers.
  • It adds the "PSNode Game CA" certificate to your trusted certificates. It is locked to growtopia1.com and growtopia2.com, so it can't be used for any other website (banks, email and so on).

It installs nothing else, and you can undo both changes whenever you want. It needs administrator rights because Windows protects those two things.

While it's set up, Growtopia goes to PSNode, not the official game. Only run the file if you downloaded it from this page.

  1. Download PSNode setup
  2. Double-click PSNode-Setup.cmd. If Windows says it protected your PC, click More info and then Run anyway. Click Yes when it asks for administrator rights.
  3. Press Enter to set up PSNode.
  4. Close Growtopia completely and open it again.
  5. On the login page, type the server name your friend gave you, then log in or create an account.
Going back to the official game

Run the same file again, type R and press Enter. It removes both changes.

Want to check it yourself?

Right-click the file and open it with Notepad to read it before running it. The first lines explain what it does.
